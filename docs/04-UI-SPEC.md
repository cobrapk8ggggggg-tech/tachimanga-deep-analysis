# 04 — UI Specification / مواصفات الواجهات

> كيف تبدو واجهة Tachimanga حرفياً وكيف تُبنى. كل ما هنا قابل لإعادة الإنتاج في Flutter.

## 1. الهوية البصرية العامة

- **الأسلوب:** iOS-First — المكونات تبدو وكأنها UIKit أصلي
- **المحرك البصري:** `flex_color_scheme` + `cupertino_native` (مكونات Cupertino حقيقية من UIKit)
- **التأثير المميز:** **iOS 26 Liquid Glass** — `liquid_glass_controller.dart` + `liquid_glass_tab_bar_padding.dart` — شريط التبويب السفلي والشرائح بتأثير الزجاج السائل الشفاف
- **الأوراق السفلية:** `cupertino_modal_sheet` — نفس سلوك iOS بسحب للإغلاق مع مقاومة مطاطية
- **التنبيهات:** `DWAlertController` — نسخة مطابقة لـ UIAlertController
- **مؤشرات التحميل:** `SVProgressHUD` — نفس HUD الأصلي

## 2. البنية التنقلية (Navigation)

### الهاتف (عمودي)
```
┌────────────────────────────────┐
│  شريط علوي مخصص لكل تبويب      │
│  ─────────────────────────────│
│                                │
│        محتوى التبويب           │
│                                │
│  ─────────────────────────────│
│  📚  🔎  ⬇️  🕘  ⚙️           │ ← شريط تبويب زجاجي (Liquid Glass)
└────────────────────────────────┘
```
**التبويبات الخمسة:** Library · Browse · Downloads · History · More(الإعدادات)
- ملف التعريف: `navigation_bar_data.dart` في الثوابت
- الشاشات الداخلية تُدفع بـ `go_router` مع انتقالات iOS (slide from right)

### الآيباد/الشاشات الكبيرة
- `big_screen_manga_details.dart` — تفاصيل المانجا بعمودين (غلاف + قائمة فصول)
- `duo_reader_toolbar_layout.dart` — القارئ بأدوات على جانبين
- دعم Apple Pencil: `apple_pencil_double_tap` (نقر مزدوج = تقليب صفحة!)

## 3. السمات (Themes)

- **المحرك:** flex_color_scheme مع `ThemeDefine` مخصص
- **سمات مكتشفة بالاسم:** Midnight Dusk، Tako، Monet (ديناميكي من خلفية النظام!)
- **امتدادات:** `ThemePureBlack` (أسود OLED حقيقي)، `ThemeSchemeColor`، `ThemeBlendLevel` (مزج الألوان بشفافية قابلة للضبط)
- **الوضع:** Light / Dark / System لكل سمة
- **السمة الافتراضية:** Midnight Dusk (تقليد Tachiyomi)
- **الخط:** خطوط مخصصة عبر `FontManifest.json` + خطوط النظام iOS

> للحصول على نفس السمات حرفياً: انسخ `src/constants/app_themes/` من مستودع Sorayomi — إنه مفتوح المصدر!

## 4. شاشات بالتفصيل

### Library (المكتبة)
- AppBar: أيقونة بحث + فلتر + فرز + قائمة/شبكة
- تبويبات التصنيفات أفقياً قابلة لإعادة الترتيب
- شبكة أغلفة مع شارات (عدد الفصول الجديدة، تنزيلات، تتبع)
- ضغط مطول → وضع تحديد + شريط إجراءات سفلي زجاجي
- فارغة → `library_manga_empty_view` مع توجيه للاستكشاف

### Browse (الاستكشاف)
- أقسام: المصادر الأخيرة، الإضافات
- بطاقات إضافات: أيقونة، اسم، لغة، نجمة (GitHub stars)، حالة التثبيت
- بحث شامل: يكتب → نتائج مصنفة حسب كل مصدر (Quick Search cards)

### Manga Details
- غلاف بعرض الشاشة مع تدرج أسفل
- عنوان كبير، شارات (حالة، نوع المحتوى NSFW)
- صفوف أيقونات: تتبع، ملاحظة، مشاركة، تحميل الكل
- قائمة فصول مع: شارة new، شرائح تقدم، "scanned by"
- شريط سفلي: تحديد فصول، تنزيل، علامة كمقروء

### Reader (القارئ)
- شاشة كاملة، لمس واحد يخفي/يظهر الأشرطة
- شريط علوي: اسم المانجا + الفصل + إغلاق
- شريط سفلي: شريط تمرير الصفحات + زر إعدادات + وضع القراءة
- إعدادات القارئ: ورقة سفلية زجاجية بأقسام (وضع، اتجاه، حجم المسافات، خلفية، تنقّل)
- Page Curl: CustomPainter برسم فيزيائي لقلب الورقة (ظلال + انحناء)

## 5. تفاصيل دقيقة للنسخ الحرفي

| العنصر | التفاصيل |
|---|---|
| اللمس 3D | Quick Actions على الأيقونة |
| Haptics | اهتزاز خفيف عند التحديد/قلب الصفحة |
| سحب للتحديث | في المكتبة والاستكشاف والتحديثات |
| Skeleton loaders | هياكل رمادية أثناء التحميل |
| Hero transitions | الأغلفة تتوسع لشاشة التفاصيل |
| أشرطة تقدم رفيعة | أعلى الشاشات أثناء جلب البيانات |
| Scroll-to-top | نقرة على التبويب النشط |
| Grid sizing | `grid_count_controller` + `grid_cover_min_width` — الشبكة تكيّف تلقائياً |

## 6. إمكانية الوصول (Accessibility)
- دعم Dynamic Type (تكبير خط iOS)
- تباين عالٍ في السمات
- مناطق لمس ≥ 44pt
- دعم VoiceOver عبر دلالات Flutter القياسية

## 7. كيف تستنسخ الواجهة 1:1 في مشروعك

1. **Fork Sorayomi** — الواجهة الجاهزة 90% مطابقة (هذا التطبيق مبني عليها)
2. انسخ تعديلات MangaCrush البصرية:
   - أضف `cupertino_native` + `cupertino_modal_sheet`
   - نفّذ Liquid Glass عبر `UIVisualEffectView` أصلية (قناة platform channel) أو انتظر دعم Flutter الرسمي
   - انسخ أوراق الإعدادات (`*_popup.dart`, `*_tile.dart`) — أسماء الملفات موجودة في `data/extracted/app_dart_files_full.txt`
3. اختبر كل شاشة على الآيفون بمقاسات 6.1" و12.9"
